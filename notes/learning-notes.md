# Learning Notes

## Que es Wazuh?

Es una plataforma open source de seguridad, combina capacidades de SIEM y XDR, recolecta logs, eventos (SIEM) y puede actuar ante cualquier evento malicioso (XDR).

## Componentes Principales

- Wazuh server: Recibe informacion de los agentes.
- Wazuh Indexe: almacena e indexa datos para busquedas.
- Wazuh dashboard: interfaz eb para ver agentes, eventos y alertas.
- Wazuh Agent: componente instalado en endpoints que queremos monitorear.
